# Forest precipitation dummy data

A completely fictional dataset of daily precipitation

## Usage

``` r
forestprecipitation
```

## Format

### `forestprecipitation`

A list with 2 dataframes (january, february) containing 2 columns, and 6
rows. February intentionally resets to 1970-01-01

- time:

  The date on which the imaginary rainfall was measured took place, in
  yyyy-mm-dd format

- rainfall_mm:

  Rainfall in mm
